# Harold Sanders memorial website

Open index.html in a browser after extracting the ZIP. Upload the contents of this folder to any static web host. No external fonts, scripts or build tools are required.

All seven original photographs are included in assets. Click a photograph to view the original. Add photos by copying a figure in index.html and editing its path, caption and alt text. Add video links or embeds using the commented examples near the end of index.html.

The obituary follows the supplied Word document, with a minor grammar correction and the family-provided aircraft list. Confirm donation wording before publishing.

Review note: the Air Force portrait is labeled A/3C (Airman Third Class), while the obituary says Airman 4. The original obituary wording is retained pending family confirmation. Photo captions avoid unconfirmed names and dates.
